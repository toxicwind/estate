## Finding 3
A concrete practitioner workaround for the 404 class of NIM failures, posted August 20, 2026 as an educational carousel by creator Aniket Karmakar (@_saudade_._._, 530 followers, thin account but specific technical advice): when wiring Claude Code to NVIDIA NIM, do not trust the catalog or docs for the model name. Instead, query the running NIM deployment's /v1/models endpoint with curl and an Authorization bearer header, then copy the exact id returned as MODEL_NAME. Claude Code may request built-in aliases (haiku, sonnet, opus) and get 404s; the fix is exporting ANTHROPIC_DEFAULT_HAIKU_MODEL, ANTHROPIC_DEFAULT_SONNET_MODEL, ANTHROPIC_DEFAULT_OPUS_MODEL, and CLAUDE_CODE_SUBAGENT_MODEL mapped to the real NIM model id. Tool calling support is required for Claude Code's agent features, and the key belongs in a local .env ignored by git, never pasted into a post, screenshot, repository, or chat. The mechanism generalizes: ids the catalog lists can mismatch the ids the endpoint serves, which is exactly the class of silent 404s that model-routing configs hit.

## Finding 4

Commenters on the September 5 RGSecurityTeam Facebook reel report the service is unavailable in Pakistan and Bangladesh, with one writing 'Not available in Pakistan.. faaa.' A separate September 12 Instagram reel by creator @i295pro (110 followers) shows a Russian user registering on the NVIDIA Developer Portal and hitting a phone-number verification step that is unavailable for Russia and Kazakhstan; he jokes about trying numbers from four different countries before giving up, with the platform's synthesis noting the system blocks by more than IP. The account is small, so this reads as one user's experience rather than a measured survey, but the regional-unavailability reports recur across two independent comment sections and one video.
