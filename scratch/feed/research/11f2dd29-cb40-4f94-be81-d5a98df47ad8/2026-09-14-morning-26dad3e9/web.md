## OpenAI opens the Agents API in public beta
The harness behind Codex became a public API on [September 10](https://www.marktechpost.com/2026/09/10/openai-launches-the-agents-api-in-public-beta-putting-the-codex-harness-behind-one-api-call/), when OpenAI's [Agents API](https://openai.com/index/introducing-the-agents-api/) entered public beta. A single call naming the task, model, tools, and environment builds a production-ready agent.

OpenAI hosts and maintains the harness while you pick the compute: an OpenAI-managed sandbox, your own infrastructure, or one of nine partner sandboxes. It absorbs the plumbing: automatic context compaction, subagents with independent contexts, and MCP alongside custom functions and web search. You pay only for the tokens and tools your agents use, the beta is open to all developers, and data stays US-only with Zero Data Retention unsupported for now.
