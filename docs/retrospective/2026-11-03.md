### Phase 2 — The freeinference short-answer race (found in BOTH tau and wtf)

**The bug:** freeinference rate-limits **concurrent** embed batch requests and answers the loser with HTTP 200 + `{"data":[]}` — empty, no error. Any `Promise.all([embedA, embedB])` loses a side ~60-75% of runs.

**Evidence:**
- `pkg-semantic.ts` did `Promise.all([embedMany(ours), embedMany(canary)])` → grades flipped `twin/fork-only/empty` nondeterministically per run. 5/5 measured: 3 short-answers.
- `lsp/semantic.ts` (tau's committed LSP semantic disambiguation layer, `913680a6a7`) did `Promise.all([embedOne(query), embedMany(targets)])` — same race shape, silent degradation to "structural order kept".

**Fix applied:** Serial embeds + full-answer invariant (`vecs.length === inputs.length` AND dim check per-vector) + one retry after 900ms. The additive degrade contract still holds for sustained outages.

**Proof:** 8/8 fresh-process runs stable on `pkg-semantic`. 5/5 `embedded:true` on `lsp/semanticRank`.

**Commits:**
- tau `4b6a7eae19` — lsp semanticRank embed race fix
- wtf `ce9ff9b` — pkg-semantic embed serialization + leaf bug fix

### Phase 3 — Single-stamp guarantee (squawk/bge-xref)

**Problem:** `hasXref` skip has a TOCTOU hole — two concurrent invocations can both pass the check, then both stamp. Need a **lock**.

**Fix:** `withTodoLock()` — per-todo `O_EXCL` file lock (`<todo>.xref.lock`) wrapping the entire read→recall→rank→stamp cycle:
- `O_EXCL` on open → exclusive acquisition
- Stale steal: lock file >60s old = stolen
- 5×400ms retry loop before failing
- Atomic write: `file.tmp` → `renameSync(file)` — never a torn footer
- `run=` id in every footer for auditability

**Proof:** Two simultaneous `--todo` runs → exactly 1 footer, winner stamps, loser logs `skip (has touches:)`, zero lock residue.
