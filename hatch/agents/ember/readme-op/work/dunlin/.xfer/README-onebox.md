## What Is This?

This is a **systems analysis of human communication failure modes** — specifically, the pattern where one person offers additive information ("I had a different experience") and the other person receives it as corrective/replacement information ("You are saying I am wrong").

We call this **Experiential Monoslotting** (common name: The One-Box Problem).

### The Core Observation

When most people encounter a category of experience — jockstraps, sex positions, AI prompts, cooking methods — their brain creates **one mental slot** and fills it with their first data point. That slot is full. When someone offers a second data point, the brain cannot add a second slot. It can only interpret the new data as an attempt to **replace** the existing data.

This is not a personality flaw. It is a **cognitive architecture default** that becomes pathological under stress, identity threat, or affective load.

### Who This Affects

- **Open-topology thinkers** (~15% of population): See many solutions per category. Pay high cognitive tax. Often accused of being "difficult" or "overthinking."
- **Closed-topology thinkers** (~60% of population): See one solution per category. Fast decisions. Often feel "invalidated" by open-topology input.
- **Mixed-topology thinkers** (~25% of population): Context-dependent. Some categories open, some closed.

### Why This Matters Now

We have built **agentic AI systems** that can hold 10,000 categories open simultaneously. We have built machines that can steelman any position in 0.3 seconds. And we are using them to argue about jockstraps.

The One-Box Problem is not a bug in any individual. It is a **civilizational firmware mismatch** between brains evolved for savanna threat-detection and minds capable of infinite category expansion.

## Key Concepts

| Term | Definition |
|------|------------|
| **Experiential Monoslotting** | The cognitive pattern where a category collapses to one mental slot, causing new data to be perceived as replacement rather than addition. |
| **Category Collapse** | The reduction of a multi-slot category (∆) to a single data point (∆×¹) under stress or identity threat. |
| **Nullification Illusion** | The perception that additive data (∆×ⁿ) is corrective data, because the filing system has no adjacent slots. |
| **Premature Cognitive Commitment** | (Chanowitz, 1981) Once information is accepted as "true," it becomes mindlessly resistant to revision. |
| **Object Constancy** | The capacity to maintain a stable internal image of another person independent of their current behavior. |
| **Mentalization** | The ability to understand that other people have minds with different knowledge, beliefs, and intentions. |
| **Open Topology** | Cognitive architecture with many slots per category. High cognitive load. Sees 99% of solutions. |
| **Closed Topology** | Cognitive architecture with one slot per category. Low cognitive load. Misses 99% of solutions. |
