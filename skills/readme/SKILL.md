# readme

Maximal README engineering: badges, aesthetics, star-magnet copy, repo-ready.

## Doctrine
- Badges first, always (top of file, right-aligned, for-the-badge style)
- Copy that earns stars: answer "why should I care?" in first viewport
- Aesthetics are correctness: mermaid, tables, syntax-highlighted code
- Links are first-class: no placeholders, no TODOs
- License + security up front

## Structure
1. Title + subtitle + badges
2. Hero — what/why/who
3. Feature bullets (not prose)
4. Diagram or screenshot
5. Quick start (3 commands max)
6. Architecture
7. Config / optional services
8. Dev / contributing
9. License + security

## Apply
Read existing README, preserve technical accuracy, upgrade presentation to maximal.
