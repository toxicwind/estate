# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1.

Be respectful. Focus on the code and the design, not the person on the
other end of the review. Disagreement is fine and expected; personal
attacks are not.

Report unacceptable behavior via GitHub's private security advisory
workflow on this repository
(<https://github.com/acoyfellow/hashline-pi/security/advisories/new>) —
the advisory mechanism accepts non-security reports too and delivers
them privately to the maintainer. Reports will be handled
confidentially.
