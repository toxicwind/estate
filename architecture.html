Why These Three Forks Exist
1. Architectural Incompatibility
ik_tq uses a completely different "build_*.cpp" model-builder pattern (77 unique files). turboquant and beellama share ~190 files.
2. Mutually Exclusive Core Features
turboquant owns turboquant-types (78 AST). ik_tq owns hadamard + merge + speculative. beellama owns practical DFlash speculative.
3. Depth vs Surface Integration
grep=80 + AST=0 = name-dropped. grep=80 + AST=127 = deeply woven into code. Only MLA is truly shared across all three forks.
