# easybash/bash-coding-style-guide

Source: https://github.com/easybash/bash-coding-style-guide

## Rules adopted

- `source` over `.` in new code.
- Underscore naming for variables.
- Shebang uses `env` for PATH-based resolution.

## Notes

easybash is based on the Google Shell Style Guide. Where it agrees with
bahamas10 and guitarrapc, the estate follows the consensus.
