# guitarrapc/bash-styleguide

Source: https://github.com/guitarrapc/bash-styleguide

## Rules adopted

- File header is mandatory.
- Consistency over correctness: "When in doubt, prioritize consistency."
- ShellCheck on every PR.
- EditorConfig for indentation.

## Quoted text from upstream

> Write a brief comment at the top of the file describing its purpose.
> When in doubt, prioritize consistency. By using a single style
> consistently throughout the codebase, you can focus on other (more
> important) issues.
